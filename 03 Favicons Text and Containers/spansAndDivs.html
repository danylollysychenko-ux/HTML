what are <spans> and <div>s?

<span> - Inline container

  • The span tag is an inline container
  • groups a part of text or other inline element without breaking document flow
  • Mostly used to apply styles like colors and fonts inside text elements

Example

This paragraph contains a span to color this text ,but not this text. Notice the change was inline and did not start on a line or add one after

<div> - Block Container

  • The div tag is a block-level container
  • It is used to group larger sections of html content
  • It creates a block that takes up the full width of its parent container, pushing content before and after to new lines.
  • Often used to divide a page into sections or containers
