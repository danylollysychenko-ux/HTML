Text formatting

Note: These tags are mostly meant for sematic value (how things like screen readers interpret the text), it is often best to control appearance with CSS.

  • <b> can be use to make text bold*less common
  • <strong> can be use to make text bold,but with semantic value
  • <i> can be use to make text italic*less common
  • <i> can be use to make text italic,but with more sematic value
  • <em> can be use to make text italic, but with more sematic value
  • <u> can be use to make text underline *better with CSS
  • <small> can be use to make text small *better with CSS
  • <sub> can be use to make text subscript
  • <sup> can be use to make text superscript
  • <mark> can be use to make text highlighted
  • <del> can be use to make text strikethrough
  • <code> can be use to make text code
