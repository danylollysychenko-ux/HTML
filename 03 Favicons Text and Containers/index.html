Favicons

To demo favicons, we will put an image of a dude

Recommended Size of a favicon is 96 pixels by 96 pixels

Supported file types include:

  • .ico
  • .png
  • .gif
  • .jpeg or jpg
  • .svg

To add a favicon add the following to the <head> section. 

            
<head>
    < rel="icon" type="image/jpeg" href="favicon.jpg" >
</head>
