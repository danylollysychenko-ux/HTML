Forms are one of the most important parts of an webpage

A form is a section of a webpage that collects user input.

The "action" attribute of the form tag says where the data should be sent

The "method" attribute of the form tag is used to indicate how the data is sent (GET and POST are most common, but there is also PUT, PATCH and GET)

  • GET: Sends values through the url - not very secure, but that's not always critical
    • Used for RETRIEVING data
    • This should never change the state of something on a server
  • POST: Sends data to create a new resource
    • Does not send data in the url. Sends as a seperate payload in the request
  • PUT: Replaces an entire resource
  • PATCH: Updates a part of a resource/record
  • DELETE: Deletes a resource

All form elements passed to another endpoint should have NAME attributes
