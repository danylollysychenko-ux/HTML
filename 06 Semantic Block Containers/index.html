Semantic Container Elements

  • Header
  • Main
  • Aside
  • Footer
  • Nav

Semantic HTML refers to the practice of using HTML tags that clearly describe the meaning and purpose of the content they contain, rather than just its visual appearance.

The following elements are containers just like divs, but they serve a semantic purpose.

  • header
  • main
  • aside
  • footer
  • nav

Without styling, these will all look and behave the same. But to screen readers and web crawlers they mean different things and tell the technology a bit about page the page structure.
