# Intro to HTML

**HTML** - Hypertext Markup Language
**Live Server** - VS Code extension for previewing html page

## Tags
<!doctype html> - Declares the page as an html 5 page
<html> - The root element that wraps all other content
<head> - A container for meta data - information about the page, not actual content. May contain the page title
and links scripts and CSS.
<body> - Encloses all visible content like text, images and links.
